# C++ core (cache/io conformance harness)

This folder contains a minimal C++ test harness intended to validate a future C++ port of the RuneScape cache + I/O layer against shared fixtures.

## What’s covered (initial)

- `xtea_decrypt_in_place`: block decrypt parity
- `SectorChainStore`: legacy `.dat` + `.idxN` sector-chain reading
- `archive_split_payload`: multi-file archive chunk table splitting

## Fixtures

Fixtures live in `testdata/cache-fixtures/` at the repo root and are generated by:

- `npm run generate-fixtures`

## Build + run

From repo root:

- `cmake -S cpp-core -B cpp-core/build`
- `cmake --build cpp-core/build -j`
- `ctest --test-dir cpp-core/build --output-on-failure`
